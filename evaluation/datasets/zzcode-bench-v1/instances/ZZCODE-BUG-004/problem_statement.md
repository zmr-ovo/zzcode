# CLI 无法稳定定位全局 `.env` 配置

从其他工作目录启动已安装的 zzcode 时，CLI 只能依赖当前进程环境，无法定位项目安装位置的全局 `.env`，也没有显式配置文件覆盖入口。

请增加一个统一的全局环境文件定位函数：

- `ZZCODE_ENV_FILE` 已设置时优先使用该路径，并展开用户目录、返回绝对路径。
- 源码目录存在 `.env` 时使用源码目录中的文件。
- editable/file URL 安装场景能够从包的 `direct_url.json` 定位安装源目录。
- 元数据缺失、JSON 损坏或文件系统异常时安全回退，不影响 CLI 启动。
- 此任务只负责定位文件，不应读取或暴露文件内容。
