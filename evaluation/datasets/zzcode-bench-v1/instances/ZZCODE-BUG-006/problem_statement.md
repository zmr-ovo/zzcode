# 默认执行预算不足以支持常见 Coding Task

CLI 和运行时目前默认只允许 6 个工具步骤、每次最多 512 个输出 token。对于包含 reasoning 的模型，这个默认值经常在形成有效修改或最终回复前耗尽，并且 CLI 与直接构造运行时必须保持一致。

请调整默认预算：

- 默认工具步骤提高到 10。
- 默认单次模型输出预算提高到 2048 token，并在 CLI help 中说明该预算包含 reasoning token。
- `build_arg_parser()` 与直接构造 `ZZCode` 的默认值必须一致。
- 用户显式传入的值仍然生效。
- 不改变预算计数和停止条件的其他语义。
