# `.env` 变体文件未纳入私密路径隔离

工作区不仅可能包含 `.env`，还可能包含 `.env.local`、`.env.production` 等环境文件。只屏蔽精确文件名 `.env` 会使这些变体仍可被文件工具直接读取。

请扩展统一的私密路径规则：

- `.env` 和以 `.env.` 开头的文件名都属于私密环境文件。
- 文件列表不得展示这些文件。
- `read_file` 和指定路径的 `search` 不得访问这些文件。
- 判断逻辑应集中定义，工作区扫描与工具校验共用，不能维护两套名称列表。
- `.environment`、`env.example` 等普通文件不应被误判。
